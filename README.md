# 🕌 Tánger App · Rafa & Radia

Traductor español-árabe marroquí (Dārija) con micrófono para viajeros.

## Qué tiene la app

- 🎤 **Traductor con micrófono** — habla en español y traduce al árabe marroquí real (Dārija)
- 🔄 **Bidireccional** — español→árabe y árabe→español
- 🔊 **Audio** — escucha la pronunciación de cualquier traducción o frase
- 💬 **27 frases útiles** — saludos, compras, restaurante, transporte, alojamiento
- 🚨 **SOS emergencias** — 10 frases críticas con audio automático
- 🔢 **Números** — del 0 al 1000 con pronunciación
- 📖 **Guía cultural** — dinero, costumbres, transporte, comida, lugares de Tánger
- 📤 **Compartir** — envía traducciones por WhatsApp

## Despliegue en GitHub Pages

1. Ve a **github.com** → "New repository"
2. Nombre: `tanger-app` (o el que quieras)
3. Marca "Public"
4. Sube los dos archivos: `index.html` y `manifest.json`
5. Ve a **Settings → Pages → Source: main / root**
6. URL final: `https://TU-USUARIO.github.io/tanger-app/`

## Personalización fácil

Para cambiar el nombre del propietario, busca en index.html:
```
Rafa &amp; Radia
```
Y cambia por otro nombre.

## Tecnología

- PWA instalable en Android e iPhone
- IA: Claude Sonnet (Anthropic API)
- Reconocimiento de voz: Web Speech API
- Sin base de datos ni backend propio
